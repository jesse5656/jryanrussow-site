# OCP-004 — Institute Orientation and Visualization

Version: 1.0.0

Status:
Approved

Type:
Operational Change Proposal

------------------------------------------------------------------------------

## Purpose

Improve everyday orientation to the existing Russow Institute architecture
without redesigning the architecture or creating a competing source of truth.

------------------------------------------------------------------------------

## Current State

The repository already defines Institute Architecture, Knowledge Lifecycle,
Knowledge Lineage, Canon Structure, development Phases, and the Roadmap.

These documents collectively explain the system, but no single daily
orientation view makes the knowledge-to-application loop easy to understand.

The Institute Architecture and Knowledge Lifecycle are also not currently
prominent in the existing MkDocs Institute navigation.

------------------------------------------------------------------------------

## Approved Operational Change

The repository shall:

1. Add a Master Institute Map to the existing Institute Architecture.
2. Preserve existing organizational relationships.
3. Show curriculum and teaching as outputs of mature knowledge.
4. Link the map to Knowledge Lifecycle, Knowledge Lineage, Canon Structure,
   Phases, and Roadmap.
5. Expose Institute Architecture and Knowledge Lifecycle through MkDocs.
6. Add a Daily Orientation reference to Daily Operations.

------------------------------------------------------------------------------

## Scope

- `docs/institute/INSTITUTE-ARCHITECTURE.md`
- `docs/operations/researcher/DAILY-OPERATIONS.md`
- `mkdocs.yml`
- `docs/architecture/ocp/OCP-004-INSTITUTE-ORIENTATION.md`

------------------------------------------------------------------------------

## Governance Boundary

This change improves documentation accessibility, orientation, and navigation.

It does not:

- redesign the Institute;
- change constitutional authority;
- change existing organizational relationships;
- define or modify the Human Operating System curriculum;
- modify the Three-Pillar Method;
- modify Wealth Engine;
- modify Body Code;
- modify Mind Forge;
- modify Compound Performance Circle;
- create a new architecture document.

Any future Excalidraw visualization shall remain derived from the
authoritative Institute Architecture.
