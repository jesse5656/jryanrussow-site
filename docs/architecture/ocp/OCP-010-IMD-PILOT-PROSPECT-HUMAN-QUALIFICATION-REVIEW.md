## Human Qualification Boundary

The human review is a prospect-qualification decision, not client
authorization.

Protein Solutions may proceed only to an internal pre-contact qualification
step focused on the decision-blocking unknowns already identified in the
completed dossier and ranking.

The existing Pilot Authorization Package remains controlling. Before any pilot
kickoff, the Institute must establish suitability, bounded scope, realistic
evidence access, relevant personnel availability, pilot economics, exclusion
compliance, and completion of the required operational forms.

------------------------------------------------------------------------------

## Exact Next Action

Create a bounded Protein Solutions pre-contact qualification brief using the
existing Pilot Authorization Package and committed dossier evidence.

The brief shall:

- populate only facts already supported by the governed public record;
- identify evidence-access, personnel, sponsor-authority, willingness, scope,
  and economic-fit unknowns;
- define the minimum questions that a later human contact would need to resolve;
- preserve the approximately-$10,000 pilot boundary;
- avoid named-person enrichment;
- not send or authorize outreach.

A separate human decision is required before any contact is made or any pilot
prospect is finally selected.

------------------------------------------------------------------------------

3. no pilot prospect is represented as selected;
4. no outreach is authorized;
5. Governance Enforcement passes;
6. MkDocs builds successfully;
7. the scoped diff is presented for separate commit approval.
