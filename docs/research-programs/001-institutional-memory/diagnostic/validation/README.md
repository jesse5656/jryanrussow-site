# Institutional Memory Diagnostic — Validation Evidence

This directory contains canonical institutional records for validation of
Institutional Memory Diagnostic methodologies and supporting executable skills.

Validation evidence is distinct from the Research Program 001 research-evidence
library.

Research evidence supports substantive research findings.

Validation evidence records how a methodology or executable skill was tested,
evaluated, accepted, and linked to a versioned implementation.

Controlled evaluator or fixture material shall not be exposed through normal
installed-skill operating references.
